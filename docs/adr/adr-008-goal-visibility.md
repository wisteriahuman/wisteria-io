# ADR-008: 目標の構造をどこまで見せるか

- ステータス: 採用
- 日付: 2026-10-14

## 背景・課題 (Background/Problem)
- 目標から指標まで筋道を立てて考えていることは、見せれば「考えて動く人」の証拠になる
- 一方で、選考上の目標をそのまま見せると、見る企業に「数ある応募先の一つ」と読まれる
- KGI・KSF といった用語を繰り返すと、くどくなる
- ポートフォリオは「この人は何者か」を見せる場所である

## 決定事項 (Decision)
- 人生の目標 → 就活軸 → 今やっていること、の構造を About に置く
- このサイトの目的 → 成功の条件 → 指標（実際の数値つき）の構造を、深い層（`/infra`・リポジトリ）に置く
- 2つの構造は同じ形にそろえる
- 選考上の目標はどこにも出さない
- KGI・KSF という用語は表の層に出さない

### 理由 (Reasons)
- 人生の目標から今の行動までがつながっていることが、ポートフォリオの一番の中身になる
- このサイトの目的と指標は「このサイトをどう作ったか」の話で、作品の一つとして深い層に置くのが合う
- 2つが同じ形なら、「人生も作るものも同じ考え方で組み立てる人」と伝わる

### 受け入れるトレードオフ (Accepted Trade-offs)
- 人生の目標を公開するため、公開して問題のない言葉を選ぶ必要がある

## 検討した別の選択肢 (Alternatives Considered)
- **すべて非公開にする**: 無難だが、考え方の筋道という最大の差別化を捨てる
- **このサイトの目的と指標だけを表に出す**: プロジェクトの説明になり、人物像が伝わらない
- **選考上の目標まで見せる**: 正直だが、見る企業に悪い印象を与える

## 議論 (Discussion)
- 最初は人生の目標を外に出さない案だったが、「ポートフォリオは人物を見せる場所」という指摘で逆にした
- 人生の目標の文言とその下の構造は、段階②-a で詰める
