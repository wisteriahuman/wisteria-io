# ADR-008: 目標の構造をどこまで見せるか

- ステータス: 採用
- 日付: 2026-10-15

## 背景・課題 (Background/Problem)
- 目標から指標まで筋道を立てて考えていることは、見せれば「考えて動く人」の証拠になる
- 一方で、選考上の目標をそのまま見せると、見る企業に「数ある応募先の一つ」と読まれる
- KGI・KSF といった用語を繰り返すと、くどくなる
- ポートフォリオは「この人は何者か」を見せる場所である

## 決定事項 (Decision)
- 人生の KGI → KSF → KPI を About に置き、「人生の KGI」「KSF」「KPI」を見出しとして出す。用語は見出しに1回ずつだけ使い、文章の中では繰り返さない
- このサイトの目的 → 成功の条件 → 指標は要件書（`requirements/README.md`）に残す。`/infra` では指標の数字だけを見せ、KGI という言葉は使わない
- 選考上の目標はどこにも出さない
- 根底にある考え（KGI の理由）は、本人が自分の言葉で書けるまで置かない

### 理由 (Reasons)
- 人生の目標から今の行動までがつながっていることが、ポートフォリオの一番の中身になる
- 一文だけを置くと標語に見えるが、KGI として下に KSF・KPI がつながっていれば、目標として読まれる
- このサイトの目的と指標は「このサイトをどう作ったか」の話で、作品の一つとして深い層に置くのが合う

### 受け入れるトレードオフ (Accepted Trade-offs)
- 人生の目標を公開するため、公開して問題のない言葉を選ぶ必要がある
- KGI・KSF という用語を表に出すので、くどく見えないよう見出しに限る

## 検討した別の選択肢 (Alternatives Considered)
- **すべて非公開にする**: 無難だが、考え方の筋道という最大の差別化を捨てる
- **このサイトの目的と指標だけを表に出す**: プロジェクトの説明になり、人物像が伝わらない
- **選考上の目標まで見せる**: 正直だが、見る企業に悪い印象を与える
- **「人生の KGI」だけを見出しにし、下は普通の言葉で書く**: 用語は減るが、3段の構造が見えにくい

## 議論 (Discussion)
- 最初は人生の目標を外に出さない案だったが、「ポートフォリオは人物を見せる場所」という指摘で逆にした
- 2026-10-14: 最初は「2つの構造（人生とこのサイト）を同じ形にそろえる」とし、KGI・KSF の用語は表に出さないとしていた
- 2026-10-15: このサイトの KGI は表に出さなくてよく、人生の KGI・KSF・KPI は用語ごと出した方が納得感がある、と判断し直した。「同じ形にそろえる」は外した
- 2026-10-15: KGI は「みんなの役に立つ」。最初の下書き「考え抜くことで、より大きな課題を解決できる人になる」は在り方（KSF）を KGI の位置に置いていたため浅く感じた
