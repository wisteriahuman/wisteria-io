# ADR-005: 日本語のみで作る

- ステータス: 採用
- 日付: 2026-10-14

## 背景・課題 (Background/Problem)
- 英語版を用意するかを決める必要があった
- 想定する見る人は国内の企業の人事とエンジニアで、勤務地も東京を希望している

## 決定事項 (Decision)
- 日本語のみで作る

### 理由 (Reasons)
- 見る人が日本語話者であり、英語版を作っても届く相手が増えない
- 閲覧数は指標にしていないため、英語で数を稼ぐ必要がない
- 翻訳の手間を、ほかのこだわりに回した方が効果が大きい
- 自分で書いた英語や機械翻訳は、日本語の文章ほど質を担保できない

### 受け入れるトレードオフ (Accepted Trade-offs)
- 海外の企業や英語話者には読まれない

## 検討した別の選択肢 (Alternatives Considered)
- **日英の2言語**: 届く範囲は広がるが、翻訳と保守の手間に見合う相手がいない
- **翻訳サービスで自動生成**: 手間は小さいが、文章の質を担保できない
