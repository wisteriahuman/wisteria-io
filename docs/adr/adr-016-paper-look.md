# ADR-016: 見た目を、リングノートから破り取ったページを台紙に貼った形にする

- ステータス: 採用
- 日付: 2026-10-15（2026-10-16 に「紙の質感」から改訂）

## 背景・課題 (Background/Problem)
- 段階①は、暗い配色を保ったまま中身と並び順を直した
- 段階②-a で、表は普通の自己紹介に見せ、その下に作りの証拠を置く方針にした（→ [アイデアソン](../ideathon/2026-10-15-design.md)）
- 最初は「紙の質感」（生成りの地・ベージュの罫線・藤色・明朝の見出し）にした。staging で見た本人から「色味が合ってない」「AI っぽい」「罫線ならノートっぽいのに、ノートじゃない部分がたくさんある」と言われた
- 原因は、テーマを理由から決めずに、消去法で「紙」を選んだことにある。罫線はただの飾りで文字が線に乗らず、角の丸い箱や札など、ふつうの Web サービスの部品が混ざっていた

## 決定事項 (Decision)
- テーマは大学のリングノート。テーマは理由から出す
- リングノートから破り取ったページを、セクションごとに1枚ずつ、のりで台紙に順に貼った形にする。紙と紙の間に台紙が見え、縦にスクロールすると貼られた紙を順に読んでいく。紙の高さは中身に合わせる
- 紙の上の端には、リングから破り取った跡を描く。穴のところで紙がちぎれ、穴と穴の間に紙の切れ端が残る。破れ方は紙ごとに変える（同じ形の繰り返しは機械が作ったように見える）。リング・ミシン目・テープは描かない
- 白に近い紙に水色の罫線を引き、文字を罫線の上に乗せる。罫線の間隔は本文の行の高さ（28px）にそろえる。赤い余白線は引かない
- 大学ノートの決まりごとの欄を使う。ページの上の「Date」に最後に更新した日、記事には「No.」（何本目の記事か）と書いた日
- PC もスマホも同じく縦に並べる。PC は紙を広めにする
- 寸法は rem で書く。ブラウザの標準の文字サイズを大きくした人には、文字と罫線が一緒に大きくなる
- テーマから外れる部品を置かない。作品は箱にせず罫線の上に書き、受賞は蛍光ペン、技術は1行の文、経歴の日付は本文の左の日付欄（スマホでは本文の上の行）、ボタンは下線の文字のリンクにする
- 「この部分の作り」は余白に書き足したメモにし、前の判断は消さずに取り消し線で残す
- 文字は黒、リンクは青のボールペンの色、蛍光ペンは黄色にする（staging で藤色と見比べて本人が選んだ）
- 実績やリンクの押せる高さは 24px 以上（WCAG 2.5.8 の AA）にし、空行を挟まずに続けて書く。ナビのリンクとボタンは 44px 以上
- 見出しも本文もゴシックにする（日本語は端末のフォント、ADR-009）。手書きの書体は英字だけ（Caveat）にし、紙の上の欄に書き込む番号と日付、英語のセクションの見出しにだけ使う。落書きは描かない
- GitHub・X・AtCoder へのリンクは、紙に貼ったシールにする（白い縁の型抜き、少し傾けて貼る）。作品の受賞は朱色の判子にして、作品の題の横に押す。最初の画面の実績3つは蛍光ペンのまま
- 明るい紙だけにし、ダークは作らない
- 貼った紙は動かさない
- OGP 画像も同じ形にする。台紙に破り取った紙を1枚貼り、上の欄に No.・Date、トップは名前・所属・蛍光ペンの実績、記事は題を書く

### 理由 (Reasons)
- このサイトの見た目が表す理由を、本人が2つ決めた
  - 考え続け、考えたことを言葉にして残す（根底はパスカルの考える葦）。ノートは考えたことを書き残す場所
  - 大学ノートは、大学で学び、書き留めながら考えている今の自分を表す
- 説明しなくてもノートと分かるので、理由がそのまま伝わる
- ノートでも直すときは消さずに線を引く。ADR を消さずに上書きしていくこのリポジトリのやり方と同じ形になる
- 部品をすべてノートの書き方に置き換えると、画面は罫線の上の1列になり、人事の30秒の邪魔にならない
- 綴じたノートは、横綴じなら横に、上綴じでもリングの裏へめくるので、1画面に1ページずつの形になり、縦のスクロールとは合わない。切り取って台紙に貼った紙なら、1枚ずつ分かれて縦に並んでいる理由がそのまま説明でき、スクロールで順に読める
- 紙を1枚ずつに分けると、1画面に収まらないセクションも、紙を長くするだけで読める

### 受け入れるトレードオフ (Accepted Trade-offs)
- 文字を罫線に乗せるため、見出しや画像の高さも罫線の間隔の倍数にそろえる手間がかかる
- 大学ノートは学生の自由帳に見えるおそれがある。手書き風の飾りを使わないことで防ぐ
- 紙の長さが中身で変わるので、本物のノートのページより長い紙が出る
- 押せる高さを 24px にしたので、指の大きい人には 44px より押しにくい
- OS のダーク設定の人にも、明るい画面を出す

## 検討した別の選択肢 (Alternatives Considered)
- **紙の質感（生成り・ベージュの罫線・藤色・明朝）**: この ADR の最初の決定。罫線が飾りになり、箱や札が混ざって、ノートに見えるのにノートではない部分が多かった
- **校正刷り（組まれた文書に赤字）**: 判断が変わった跡を赤字で表せるが、編集の仕事を知らない人には何の絵か伝わりにくい
- **上開きのリングノート（紙ごとにリングを描き、縦にめくる）**: 紙ごとにリングがあると、ノートが何冊も縦に並んだ絵になる。本物は1冊に1つのリングを全ページで共有し、めくったページはリングの裏へ回るので、縦のスクロールでは表せない。めくれる動きも、長い紙では見えている部分が振れるため控えめにしかできず、見て分からなかった
- **見開き（横綴じのノートを開いた形）**: PC の幅を使えるが、横にめくるノートの右のページを縦にスクロールすることになり、ノートとして不自然
- **横にめくる（中身を画面の大きさのページに流し込む）**: ノートとして一番正直だが、人事は横にめくれることに気づきにくい
- **レポート用紙・連続帳票・ロール紙**: どれも縦にめくれるが、レポート用紙はノートほど親しみがなく、連続帳票とロール紙は考える紙ではない
- **研究ノート・方眼ノート**: 記録の決まりは ADR と重なるが、ノートだと分かるまでに一拍かかる
- **葦と藤（育つもの）・台本や譜面**: 植物の絵は飾りになりやすく、台本や譜面は比喩の説明が要る
- **スイス・ミニマル（白地・黒の罫線・等幅の見出し）**: 表が一番普通に見えるが、角張った線が初期表示のように見え、作っていない印象を与える
- **暗い配色の延長**: 無難だが、よく見る形

## 議論 (Discussion)
- リンクがただの下線で物足りないと言われ、アイコン・判子・手書きの書体を比べた。本人の「シール的な感じ」を受けてリンクはシールにし、判子は「認められた印」の意味が合う受賞に使った。手書きは、日本語の書体が数 MB になるため英字だけにし、本物のノートでも手書きになる欄の数字と見出しに絞った
- 大学ノートの最初の版には左の赤い余白線を引いていた。本人に「note 書くときこんな赤い線入れるか？」と言われ、調べ直すと赤い余白線はアメリカのノートの決まりで、日本の大学ノートには無かった。外して「No.」「Date」の欄を使うことにした
- 同じとき「スマホビューしか今考えていない？」とも言われた。PC はスマホの1列を広げただけで、両側が空いていた。一度、PC をノートの見開き（左のページを止め、右のページをスクロール）にした
- 見開きを見た本人に「スクロールできそう感がない。だってノートだもん。それなら無理やりノートにする必要性がなくなってしまう」と言われた。横に綴じたノートは縦にスクロールしない。上で綴じた紙なら縦にめくれるので、レポート用紙・連続帳票・ロール紙と比べ、ノートのまま縦にめくれる上開きのリングノートにした（本人は「note は好きだった」）
- 上開きのリングノートで紙ごとにリングを描き、紙が置かれる動きを付けた。本人に「リングが全部一緒だと思ってた」と言われた。紙ごとのリングは何冊ものノートに見え、1冊のリングを共有する形は縦のスクロールでは表せない。本人の案「リングを消して破いて貼り付けていった感じ」を受け、切り取ったページをのりで台紙に貼った形にした。ミシン目とテープは描かず、「普通にのりとかで貼られている感じ」にした。紙の上の端は、本人が写真で示した「リングの切れ端みたいなやつ」（破り取ったときに穴のところに残るちぎれ跡）にした。前に「紙の破れは使わない」としたのは自由帳に見せる飾りを避けるためで、リングノートから破り取れば必ず残る跡はそれに当たらない。動きは、めくることを見せる意図が貼った紙には当てはまらないので消した
- 最初の版は実績の間に空行を挟み、押せる高さを 44px にしていた。「質素」と言われ、密度を上げるため 24px（WCAG の AA）に下げた
- 最初はスイス・ミニマルを推したが、「四角で角張っていると初心者が作った感じに見える」という指摘を受け、紙の方向にした
- 紙の質感を staging に出した後、上の指摘を受けた。本人の「デザインには理由があるはずです」「テーマは理由に置くべきです」を受けて、理由を先に決め、アイデアソンで案を広く出してからテーマを比べた
- 私は一度「表は普通の文書にし、ノートの見た目は『この部分の作り』の中だけにする」案を推した。本人は、分かりやすさと理由の両方からノートを選んだ。前の失敗はノートを中途半端にしたことで、ノートを選んだことではない、と結論した
- 2026-10-23: About のスクロールで動く場面を外した（→ [ADR-008](./adr-008-goal-visibility.md)）
