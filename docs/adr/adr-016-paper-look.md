# ADR-016: 見た目を紙の質感にする

- ステータス: 採用
- 日付: 2026-10-15

## 背景・課題 (Background/Problem)
- 段階①は、暗い配色を保ったまま中身と並び順を直した
- 段階②-a で、表は普通の自己紹介に見せ、その下に作りの証拠を置く方針にした（→ [アイデアソン](../ideathon/2026-10-15-design.md)）
- ui-ux-pro-max で3つの方向（スイス・ミニマル、紙、暗い配色の延長）を出し、スマホ幅の試作で比べた

## 決定事項 (Decision)
- 生成りの地・墨の文字・罫線にする
- 見出しは明朝、本文はゴシックにする。日本語は端末のフォントを使う（ADR-009）
- 角は 6〜8px 丸め、チップは線ではなく薄い面にする
- 明るい紙だけにし、ダークは作らない
- 動きは、セクションが少し浮き上がって出る程度と、About の1場面だけにする

### 理由 (Reasons)
- 紙と罫線が「記録」の手触りになり、演出を足さずに「作り方の証拠」というテーマに合う
- 表が普通であるほど、「この部分の作り」を開いたときの驚きが大きい
- 明るい紙1つに絞ると、コントラストの確認が1回で済む

### 受け入れるトレードオフ (Accepted Trade-offs)
- OS のダーク設定の人にも、明るい画面を出す
- 明朝は端末によって字形が変わる（ヒラギノ明朝・游明朝・Noto Serif CJK）

## 検討した別の選択肢 (Alternatives Considered)
- **スイス・ミニマル（白地・黒の罫線・等幅の見出し）**: 表が一番普通に見えるが、角張った線が初期表示のように見え、作っていない印象を与える
- **暗い配色の延長**: 無難だが、よく見る形
- **スクロールでスライドのように1画面ずつ切り替える**: 1画面に収まらないセクションが読めず、人事の30秒の邪魔になる

## 議論 (Discussion)
- 最初はスイス・ミニマルを推したが、「四角で角張っていると初心者が作った感じに見える」という指摘を受けた。原因は角そのものより、黒い枠の線が初期表示に近いことにあると考え、紙の方向で角を丸めることにした
