# ADR-013: コードは MIT、記事と画像は対象外にする

- ステータス: 採用
- 日付: 2026-10-15

## 背景・課題 (Background/Problem)
- 公開リポジトリだがライセンスがなく、コードを参考にしたい人が使ってよいか分からない状態だった
- リポジトリには、コードのほかに、自分の書いた記事（`src/content/`）と顔写真などの画像（`public/`・`src/assets/`）が入っている

## 決定事項 (Decision)
- ソースコードは MIT License にする（`LICENSE`）
- 記事と画像は MIT の対象外とし、無断での転載・再利用を禁じる。`LICENSE` の冒頭と README に範囲を書く

### 理由 (Reasons)
- コードは参考にしてもらえる方が、作り方を見せるという目的に合う
- 記事と写真は自分の表現と肖像で、コピーサイトや無断転載に使われたくない
- 範囲を README と `LICENSE` の両方に書けば、読む人が迷わない

### 受け入れるトレードオフ (Accepted Trade-offs)
- 記事を引用・紹介したい人は、通常の引用の範囲を超える場合に連絡が要る
- 1つのリポジトリに2つの扱いが混ざるため、新しいファイルをどちらに置くかを意識する必要がある（→ [rules/code-structure.md](../rules/code-structure.md)）

## 検討した別の選択肢 (Alternatives Considered)
- **すべて MIT**: 単純だが、記事と顔写真まで自由に再利用できてしまう
- **ライセンスを置かない**: 何も許可しない状態になり、コードを参考にしたい人も使えない
- **記事に CC BY を付ける**: 出典を書けば再利用できるが、今は記事を広く再利用してもらう必要がない

## 議論 (Discussion)
- 記事を再利用してもらいたくなったら、記事だけ CC BY に変える
