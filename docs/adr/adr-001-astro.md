# ADR-001: 作り直しでも Astro を続投する

- ステータス: 提案中
- 日付: 2026-10-14

## 背景・課題 (Background/Problem)
- ポートフォリオを作り直すにあたり、技術選定からやり直した
- このサイトは就活で使う。人事と現場のエンジニアが、どの端末・どの回線から開いてもすぐ読めなければ役目を果たさない（→ [要件](../requirements/README.md)）
- 既存サイトは Astro 5 + Tailwind CSS 4 で、Markdown のブログと OGP 画像の生成が動いている

## 決定事項 (Decision)
- Astro を続投する

### 理由 (Reasons)
- 静的な HTML として出力され、閲覧環境を選ばない
- 中身を読ませるサイトに向いており、ブログ・OGP 生成の資産をそのまま活かせる
- 作品として見せたい部分は、ページ単位・部品単位で個別に作り込める

### 受け入れるトレードオフ (Accepted Trade-offs)
- サイト全体を一つの体験（操作できる UI など）として作る方向には向かない。自己表現は個々のページや部品で行う

## 検討した別の選択肢 (Alternatives Considered)
- **サイト自体を作品にする（ターミナル風 UI など）**: サイトそのもので自分を表現できるが、見る人に操作を求め、読みたい情報にすぐ届かない人が出る。誰でも見られることを最優先にするため不採用

## 参考 (References)
- [Astro](https://astro.build)

## 議論 (Discussion)
- 「サイトで自分を表現したい」気持ちはあるが、ポートフォリオは就活で使うものなので、誰でも見られることを優先した
- 驚きは「サイトそのものが証拠になっている」一点に集め、具体案はアイデアソンで詰める
