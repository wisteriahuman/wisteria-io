# ADR-007: 段階的に公開する

- ステータス: 採用
- 日付: 2026-10-14

## 背景・課題 (Background/Problem)
- 2026-10-17 にサポーターズのイベントがあり、スライドからサイトに来る人がいる
- 就活の選考が並行しており、その準備時間も必要
- 要件をすべて満たすには、デザインの刷新・インフラの移行など数週間かかる

## 決定事項 (Decision)
- 段階①（2026-10-17）: 今の Astro と配信のまま、中身・最初の画面・OGP を作り直す
- 段階①の公開後は、選考の準備を優先してしばらくサイトに手を入れない
- 段階②（段階①の後）: 期限なしで作り込む。②-a〜d の区切りで進める

### 理由 (Reasons)
- 全部揃うまで公開しないと、直近のイベントに間に合わない
- 段階①は「人事が30秒で分かる」に絞れば、3日で満たせる
- デザインを中途半端に変えるより、中身と並び順を直す方が効く

### 受け入れるトレードオフ (Accepted Trade-offs)
- 段階①で作った部分の一部は、段階②で作り直すことになる

## 検討した別の選択肢 (Alternatives Considered)
- **全部揃うまで公開しない**: 完成度は上がるが、直近のイベントと面接に間に合わない
- **段階①でデザインまで変える**: アイデアソンを経ずに決めることになり、こだわりきれない

## 参考 (References)
- [要件の段階](../requirements/README.md#段階)

## 議論 (Discussion)
- 段階①の公開日の目安は、もともと「面接の1週間前」としていたが、イベントの日程に合わせて 10-17 にした
