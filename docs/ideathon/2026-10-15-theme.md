# アイデアソン: 見た目のテーマ（段階②-a）

- 日付: 2026-10-15
- テーマ: サイトの見た目のテーマ（世界観・質感・色・書体・部品の形の元になる比喩）を、理由から出す。理由は本人が決めた「考え続ける。考えたことを言葉にして残す」
- 評価の軸: (1) 理由を一番よく表しているか (2) 人事がスマホで30秒見て、何者か・主な実績を拾えるか
- きっかけ: 生成りの紙・罫線・藤色・明朝の見た目を staging で見た本人から、「色味が合ってない」「AI っぽい」「罫線ならノートっぽいのに、ノートじゃない部分がたくさんある」と言われた。テーマを決めずに罫線を引いていたため
- 進め方: `ideathon` スキル。6つの視点で発散した。印は付けずに終え、テーマにつながる案を grilling で比べて決めた

## 決めたこと

| 扱い | 案 | 理由 |
|---|---|---|
| 採る | 大学ノート | 説明なしでノートと分かり、「考えたことを書き残す人」がそのまま伝わる。大学ノートは、大学で学び、書き留めながら考えている今の自分も表す（本人）。前の失敗は、ノートを中途半端にしたことにある。部品をすべてノートの書き方に置き換えれば、画面は罫線の上の1列になり、30秒の邪魔にならない |
| 取り込む | 203 消された下書き・207 前と今・209 脱皮の殻 | ノートでも、直すときは消さずに線を引く。「この部分の作り」で、前の判断を取り消し線で残す |
| 採らない | 校正刷り（203・204・207〜209・225・227 から） | 判断が変わった跡は表せるが、編集の仕事を知らない人には何の絵か伝わりにくい |
| 採らない | 研究ノート・方眼ノート | 記録の決まりは ADR と重なるが、ノートだと分かるまでに一拍かかる |
| 採らない | 葦と藤（216・223・221） | デジタルガーデンという既にある形に近く、植物の絵は飾りになりやすい |
| 採らない | 台本・譜面（218・225） | 比喩の説明が要る |

- 出た案の多くはテーマではなく、中身や機能の案だった（問いを先に置く、下書きを残す、など）。テーマはそこから拾って比べた
- 決めた見た目の中身は [設計](../design/redesign.md) の「見た目」と [ADR-016](../adr/adr-016-paper-look.md)

## 既出
- ノート風のポートフォリオ: Astro の [Classic Notebook Portfolio](https://a457ba07.previews.astro.build/themes/details/classic-notebook-portfolio/)（手書き風の書体とスケッチブックの頁）、[Cornell Notebook Portfolio](https://a457ba07.previews.astro.build/themes/details/cornell-notebook-portfolio/)、方眼紙に手書きの余白の書き込みをした [Scribbles & Semicolons](https://stardance.hackclub.com/projects/30852)。どれも手書き風の飾りでノートらしさを出している。このサイトは手書き風の飾りを使わず、罫線に文字を乗せることと部品の置き換えでノートにする
- デジタルガーデン（[Growing Developer](https://athena.hackclub.com/projects/jane-does-coding/recTFjDzq0TskvMyL) など）、Gwern.net 式の変更履歴（[Andy Matuschak の一覧](https://notes.andymatuschak.org/zVJEfiUSS8qKYEnyrXgvuKj)）、ネットワーク化されたノート（[Networked Notebooks Catalogue](https://bmannconsulting.com/notes/networked-notebooks-catalogue/)）

## 全案

前の2回と番号が混ざらないよう、201 から振った。`*` は確率の低い案。括弧は出どころの視点。

**途中であることを見せる（未完・下書き・改訂中）**
201. 読み終わりの余白 — 各セクションの最後に「ここから先は、まだ考え中」の一行を置き、決まったことと途中のことを見分けられる（体験）
202. *書きかけの文が一箇所だけある — わざと途中で終わる一文を置き、今も続く考えの気配を見つけられる（体験）
203. 消された下書きの層 — 最終稿の下に消した文面を薄く重ね、何を捨てて何を残したかをたどれる（逆転・人の行動）
204. *完成を拒む体裁 — ページ全体を下書き・仮置き・改訂中の印のある組み方にする（逆転）
205. 机の端の付箋 — まだ言葉になっていない考えを一行だけ表に置く（人の行動）
206. *冬眠する章 — 更新していない章は静かに出し、今考えている章だけ色づく（生き物）

**考えが変わった跡を残す**
207. 一行でも言い換えた記録 — 実績の脇に「最初はこう考えた → 今はこう考える」を一組添える（体験）
208. 「やっぱり違った」欄 — 過去の判断の訂正を日付つきで載せる（人の行動）
209. 脱皮の殻 — 古い版の判断や文章を脱ぎ殻として並べる（生き物）
210. *反証されたいサイト — 自分の主張に「ここが間違っているかもしれない」と先に書く（逆転）

**答えより先に問いを置く**
211. 開いた瞬間の一行 — 最初の画面か最後に、いま考えていることを一行置く（体験・舞台）
212. 問いから始まる各節 — 見出しを答えではなく問いにする（体験）
213. 答えより先に出る問い — 各作品の最初に、解こうとした問い・解けなかったことを置く（逆転・極小）
214. 結論から始まる経歴 — 経歴を今から過去へ並べる（逆転）
215. 声に出す理由 — 理由の一文を最初の画面に大きく置く（極小）

**時間の積み重なりとして見せる**
216. 木の年輪 — 更新のたびに一輪ずつ増える断面で積み重ねを表す（生き物）
217. 一行の葦 — その日いちばん長く考えたことを日付と一文で並べる（極小）
218. 譜面 — ADR を楽譜の小節のように1枚に並べる（舞台）
219. 書かない日の余白 — 更新が止まった日も空白のまま残す（逆転）
220. 渡り鳥の航跡 — 経歴を季節ごとの渡りの軌跡として描く（生き物）
221. *藤の鉢植えの定点観測 — 育てている藤を週に一度撮り、その週の一言を添える（極小）
222. *誰も読まない日の記録 — 閲覧ゼロの日にも書いた一行を刻む（人の行動）

**表と裏・読む距離を選ばせる**
223. 擬態する葦 — 触れたところだけが葦の茎のように立ち上がり、作りの根拠を見せる（生き物）
224. 黒子 — 「この部分の作り」を黒子として、小さな目印を右下に置く（舞台）
225. 台本の欄外 — 本文の横に、なぜこう書いたかのメモを細く付ける（舞台）
226. *観客席の替え — 同じ中身を要点・経緯・全部の3つの距離で切り替える（舞台）
227. *開くと本の奥付になる — 「この部分の作り」を判断の日付と版数を並べた奥付にする（体験）
228. 余白が主役の画面 — 余白に浮かぶ数語で伝え、全文は押すと現れる（逆転）
229. ゲネプロ — 自動検証を通したことを通し稽古の記録として1行添える（舞台）

**持ち帰らせる・つながりをたどらせる・別の器で渡す**
230. 抗体の記憶 — 過去の判断を、同じ問いが来たら呼び出される抗体として並べる（生き物）
231. 共生の菌糸網 — 作品・記事・判断が菌糸のようにつながって見える（生き物）
232. 帰りに持てる三語 — 閉じる前に「この人を思い出す三つの言葉」を見せる（体験）
233. 当たり役 — 受賞と大会を配役表にする（舞台）
234. 葦が風で傾く目盛り — スクロールした量に合わせて細い茎が傾く（体験）
235. 暗転 — セクションの切り替えで一瞬画面を落とす（舞台）
236. 三行で止める作法 — 記事の冒頭を必ず三行の結論にする（人の行動）
237. 未完の栞 — 途中で離れた人が、次に開くと続きに戻る（人の行動）
238. 机の写真 — 考えている途中のホワイトボードや殴り書きを載せる（極小）
239. メールで一問一答 — 届いた質問への返事を往復ごと公開する（極小）
240. 読み上げ30秒の音声 — 自己紹介と実績を本人の声で吹き込む（極小）
241. *印刷して手渡す一枚 — サイトを A4 1枚に刷れる形にする（極小）
242. 夜の延長戦 — 寝る前に浮かんだ考えをスマホから一行で残す（人の行動）
243. *やめたくなった日の手紙 — 書くのをやめたくなったとき、過去の自分の反論が出る（人の行動）
244. *ミツバチの8の字ダンス — 実績の重さと種類を、向きと長さだけの記号で示す（生き物）

## 使った視点
体験・逆転・極小・人の行動（価値系）、生き物・舞台（遠方系）

## 前提（視点役に渡したもの）
- テーマと目的: 28卒のエンジニア学生の公開ポートフォリオの見た目のテーマを、理由「考え続ける。考えたことを言葉にして残す」から出す。良し悪しは、理由を一番表しているかと、人事がスマホで30秒で何者か・主な実績を拾えるかで決まる
- 材料: 根底にパスカルの考える葦。判断はすべて ADR に書き残してから変える。トップ1ページとブログ。各セクションに「この部分の作り」があり、開くと ADR・コード・PR が見える。表は普通の自己紹介に見せる。日本語の Web フォントは使わない。前の「紙」案は、罫線が飾りで箱や札が混ざり「AI っぽい」と言われた。ノートは候補の1つで前提ではない
- 既出: ノート風ポートフォリオ、コーネル式ノート、方眼紙と手書きの余白、デジタルガーデン、Gwern.net 式、コモンプレイスブック、デスクトップ OS 風、ターミナル風、スイス・ミニマル
